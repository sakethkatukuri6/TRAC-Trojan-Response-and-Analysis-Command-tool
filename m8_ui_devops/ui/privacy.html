Privacy Policy & Telemetry Notice

Effective Date: November 2026
Scope: TRAC (Trojan Response and Analysis Command Platform) Ingestion, Analysis, and Vault Services

1. Data Processing Architecture

TRAC is an automated malware analysis and incident response command platform. When security analysts upload suspected artifacts, binaries, or archives, the platform executes isolated static inspection, sandbox orchestration, and indicator extraction. This policy outlines how submission data, derived indicators of compromise, and telemetry are collected, processed, and preserved.

2. Artifact Intake and Defanging

All binary artifacts ingested through TRAC undergo immediate cryptographic hashing and security defanging:

  • Defanged Storage: Ingested binaries are XOR-defanged before serialization to eliminate execution capability and prevent host antivirus quarantine triggers.
  • Encryption at Rest: Defanged samples are encrypted using authenticated symmetric cryptography (AES-128 / Fernet) in the secure vault.
  • No File Path Leakage: Filesystem storage paths are never transmitted or published in analysis contracts. Samples are addressed strictly through deterministic UUID identifiers (vault_id).

3. Submitter Identity & Anonymization

TRAC records submitter attribution strictly when explicitly declared during ingestion. In accordance with zero-trust audit principles, synthetic identity creation is prohibited. Submitter information is maintained in tamper-evident database audit chains alongside timestamps and client origin records.

4. Telemetry and Indicators of Compromise (IOCs)

Analysis of submitted materials derives technical indicators including network IP addresses, domain names, file hashes, process execution trees, and MITRE ATT&CK mappings. All derived IOC network indicators (domains, IPv4/IPv6 addresses, URLs) are automatically defanged (e.g., using bracket notation such as hxxp:// and dot-bracket domains) to prevent accidental navigation or click-through execution.

5. Dynamic Sandbox Telemetry

Dynamic analysis is delegated exclusively to operator-configured, network-isolated sandboxes (such as CAPEv2). Sandbox guests operate in isolated or simulated internet modes only. No live external network connectivity is permitted during automated detonation, ensuring that sample detonation does not leak analyst IP addresses or corporate telemetry to external threat infrastructure.

6. Data Retention and Destruction

Analyzed documents, telemetry, and vaulted samples are retained according to organizational data retention schedules. Authorized administrative personnel may purge individual analysis records and associated vault entries upon formal verification.

7. Compliance and Security Contact

For questions regarding security controls, audit logs, or data privacy practices within TRAC, contact the designated organizational security operations lead or review the project documentation.
